# hand_crane — 手のジェスチャーで操縦する CRANE+ V2

ノートパソコンの Web カメラに手をかざすと、Gazebo 上のロボットアーム CRANE+ V2 が
手の動きを追いかけ、手の形（パー・グー・ピース・OKサイン）で動作が切り替わる。

Docker イメージ `airobotbook/ros2-desktop-ai-robot-book-humble`

## 操作方法

| 手の形 | ロボットの動き |
|---|---|
| パー | 手を追いかける：左右→土台が旋回、上下→手先の高さ、カメラに近づける/離す→腕を伸ばす/縮める |
| OKサイン | 追いかけながらグリッパを閉じる（つかむ） |
| グー | その場で止まる（手を動かしても追わない。手の位置を戻したいときに使う） |
| ピース | 直立姿勢に戻る |
| 手が見えない | その場で止まる |
